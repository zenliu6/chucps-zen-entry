資料檔要與本網頁在同一個資料夾。若本網頁放在子資料夾，請寫成「子資料夾/portal-data.json」。
如何取得 GitHub 權杖（Token）？
  1. GitHub 右上角頭像 → Settings → Developer settings
  2. Personal access tokens → Fine-grained tokens → Generate new token
  3. Repository access 選「Only select repositories」，只勾選這個儲存庫
  4. Repository permissions → Contents 設為 Read and write
  5. 產生後複製（只會顯示一次），貼到下方
權杖會用這組密碼加密後，只存在這台裝置的瀏覽器裡，不會上傳。
